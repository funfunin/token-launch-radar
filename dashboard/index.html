How the value is fitted

Fitted on the 90 board-like live-token comparables in the sealed snapshot: log market cap on log TVL. TVL exponent 0.45, scale 3640, and the growth, maturity, category and chain multipliers at quarter strength. Out-of-sample MAE on log value 1.57 against V2's 1.73 — about an 11% cut in mean absolute log error, with ranking at least tied (Spearman +0.38 vs +0.37). The ranking is essentially V2's; the values are far more plausible.

Honest limit: the fit's residual spread is 2.03 log units, so a typical implied value is still off by a factor of about 4.6. Market cap is a noisy target — supply, float and vesting are not in the snapshot — and live caps are post-launch while this board predicts pre-token launches. An implied value is this radar's own claim, never a promise of what a token will be worth.
